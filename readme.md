# Jetpack Compose Color Naming and Theme

This document defines the color roles and corresponding color styles used for theming in the Jetpack Compose project, based on the provided design assets.

## Compose Color Roles and Suggested Mapping

| Compose Color Role | Description                      | Color from Design                       |
|--------------------|---------------------------------|-----------------------------------------|
| **primary**        | Main accent color                | Purple (used for sessions/buttons)      |
| **secondary**      | Secondary accent/support color   | Orange (activity header/buttons)        |
| **tertiary**       | tertiary accent/support color   | Orange (second variant buttons)  |
| **surface**        | Card or panel background         | White or light pastel backgrounds       |
| **background**     | App’s background                 | Light gray background                   |
| **error**          | Error indicators                 | Red (standard error color, not depicted) |
| **onPrimary**      | Text/icons on primary            | White or dark (contrast as needed)      |
| **onSecondary**    | Text/icons on secondary          | White or dark (contrast as needed)      |
| **onSurface**      | Text/icons on surfaces           | Gray or dark (contrast as needed)       |
